Built to Prove SQL Mastery

QueryQuest is a portfolio project demonstrating deep SQL proficiency — from foundational SELECT statements to advanced window functions and recursive CTEs. Every challenge is hand-crafted with real datasets and a live in-browser SQL engine.

🎯 Project Goals

  • Demonstrate SQL mastery across all skill levels
  • Build a fully functional gamified learning platform
  • Showcase frontend development with vanilla JS
  • Implement real SQL execution using SQL.js (SQLite)
  • Design a complete user progress & XP system

🔧 Tech Stack

Built entirely with web fundamentals — no frameworks, no build tools. Pure HTML, CSS, and JavaScript.

HTML5 CSS3 Vanilla JS SQL.js CodeMirror SQLite LocalStorage

📊 SQL Coverage

  • Basic queries (SELECT, WHERE, ORDER BY)
  • Aggregation (GROUP BY, HAVING, COUNT/SUM/AVG)
  • JOINs (INNER, LEFT, RIGHT, FULL OUTER)
  • Subqueries and correlated subqueries
  • CTEs and recursive CTEs
  • Window functions (RANK, ROW_NUMBER, SUM OVER)

🏗️ Architecture

  • Static site — deployable to GitHub Pages
  • SQL.js runs a real SQLite engine in-browser
  • User data persisted with localStorage
  • Modular challenge data in data/challenges.js
  • Shared utilities in js/main.js
